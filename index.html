Batch Docs

Mail-merge spreadsheet rows into finished Google Docs and PDFs.

One row, one document — generated in bulk from a single template.

See how it works Pricing

You keep the data in Google Sheets. The documents still have to be made one by one — invoices, certificates, contracts, notices, reports. Batch Docs closes that gap: write your document once as a Google Docs template using simple {{tag}} placeholders, then generate one finished document per spreadsheet row.

How it works

1

Pick a template

Point Batch Docs at your Google Docs template; it detects every {{tag}} automatically and matches tags to your sheet's columns (you can adjust any match by hand).

2

Choose the output

Google Doc or PDF, a file-name pattern built from your own columns (e.g. Invoice_{{Client}}_{{No}}), and a Drive folder.

3

Run

Batch Docs generates every document, saves it to Drive, and writes the status, a link to the file, and the timestamp back into your sheet — so you always have a complete record of what was generated, when, and where it lives.

Key features

Recipes, not repetition

Save a generation setup as a recipe inside your spreadsheet. Next month's run is one click — no re-mapping, no re-checking.

Deterministic by design

No AI guesswork: the same template and the same data always produce the same document. Built for forms and business documents that have to be exactly right, in bulk, with a history.

Private by design

Batch Docs runs inside your Google account — your spreadsheets, templates, and generated documents never leave it, and no developer server ever receives your document data. The one small exception is the license check for paid plans, which sends only your license token and an account identifier — never content. Details are in the Privacy Policy.

Batch Docs（日本語）

スプレッドシートの行データを、完成した Google ドキュメントや PDF に 変換します。 1行につき1文書——1つのテンプレートから一括生成。

データは Google スプレッドシートに揃っている。でも請求書・証明書・ 契約書・通知書・報告書といった文書は、結局1件ずつ手で作っている—— Batch Docs はその手間をなくすためのアドオンです。Google ドキュメントで テンプレートを1つ用意し、{{取引先}} {{金額}} {{日付}} のような {{タグ}} を置くだけ。あとはスプレッドシートの行ごとに、完成した文書が 自動で生成されます。

使い方

1

テンプレートを選ぶ

Google ドキュメントのテンプレを指定すると、 {{タグ}} を自動検出し、シートの列と自動で対応付けます（手動で変更も 可能）。

2

出力を選ぶ

Google ドキュメントか PDF、列の値を使ったファイル名 パターン（例：請求書_{{取引先}}_{{番号}}）、保存先フォルダを指定します。

3

実行する

全文書を生成して Drive に保存し、シートに「ステータス／ ファイルへのリンク／生成日時」を書き戻します。何を・いつ・どこに 生成したかが、シート上にすべて残ります。

特徴

レシピで繰り返しをなくす

生成設定を「レシピ」としてスプレッド シート内に保存できます。来月の運用はワンクリック。再設定も再確認も 不要です。

決定論的な生成

AI の推測は入りません。同じテンプレと同じデータ からは、常に同じ文書が生成されます。「決まった帳票を・大量に・ 正確に・履歴付きで出す」ための道具です。

プライバシー配慮の設計

処理はすべてあなたの Google アカウント 内で完結し、文書データが開発者のサーバーに送られることはありません。 唯一の例外は有料プランのライセンス確認で、送信されるのはライセンス トークンとアカウント識別子のみです（コンテンツは送信されません）。 詳細はプライバシーポリシーをご覧ください。
