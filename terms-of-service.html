1. The service

Batch Docs is a Google Sheets add-on that generates Google Docs and PDF files in bulk from the rows of a spreadsheet, using a Google Docs template with {{tag}} placeholders, and writes a status, file link, and timestamp back into the spreadsheet. Generation settings can be saved as a "recipe" inside the spreadsheet for reuse.
